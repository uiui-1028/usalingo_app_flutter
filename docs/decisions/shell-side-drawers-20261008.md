# 決定｜Design と Profile は学習画面の左右から出す引き出しにする

決定日: 2026-10-08

## 決めること

学習画面を土台にして、Design と Profile は上の左右のボタンからシートで開いていた。
ChatGPT や Claude のアプリのように、横になぞって出す形にするか。

## 決めたこと

- **左から Design、右から Profile。** 上のボタンの位置とそろえる。
- **押し出し型。** 学習画面が横へずれて角が丸くなり、端が約15%残る。残った端を押すと閉じる。
- **学習画面のどこを横になぞっても開く。** 縦の指はこれまでどおりデッキを回す。向きは
  なぞり始めで一度だけ決める。子画面や並べ替えの間は開かない。
- **上の左右のボタンは残す。** 押すとシートではなく引き出しを開く（もう一度押すと閉じる）。
- **遊び方のバーは学習画面と一緒にずれる。**
- **Design のモジュールのページは全画面で重ねる。** 閉じると Design の引き出しへ戻る。
- iPad も同じ動きにする。

## やらないこと

- iPad 専用のサイドバー（`NavigationSplitView`）
- 引き出しの上を横になぞって閉じる操作（学習画面の残った端でだけ閉じる）
- VoiceOver の細かい調整（後でまとめて行う）
