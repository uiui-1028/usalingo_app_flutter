# 決定｜Design と Profile はタブではなくメニューとして扱う

決定日: 2026-10-08

[学習画面の左右から出す引き出し](shell-side-drawers-20261008.md)の続き。

## 決めたこと

- **Design と Profile は「タブ」ではなく「メニュー」と呼ぶ。** 学習画面が主役で、メニューはときどき開くもの。
- **中身は縦 1 列。** 引き出しは幅が狭いので、Design のモジュールも Profile の数字の枠も、横に並べず縦に並べる。
- **Design のプレビューはメニューに置かない。** 見た目は各モジュールの全画面ページで確かめる。
- **一度開いたメニューは裏に残す。** 閉じても片付けず、次はすぐ出す。
- **メニューの上を横になぞっても閉じられる。**（Design は左へ、Profile は右へ）
